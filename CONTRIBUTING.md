# Contributing to Awesome Persian GenAI

Thank you for your interest in contributing! This is a community-maintained list of open-source Generative AI resources for Persian (Farsi).

## How to Contribute

1. Check that the resource is not already listed.
2. Ensure the resource is open-source and directly related to Persian/Farsi generative AI.
3. Do **not** link to other "awesome" lists or meta-lists — link to the actual model, dataset, or tool.
4. Open a pull request adding your entry to the appropriate table in `README.md`.

## Format

Add your entry in the correct category table using this format:

```
| Name | https://link-to-resource | Short one-line description. |
```

- Use the direct link to the model, dataset, or tool (Hugging Face, GitHub, etc.).
- Keep descriptions concise (one sentence).
- Sort new entries alphabetically within their category when possible.

## Categories

- **Large Language Models (LLMs)** — decoder-only or encoder-decoder models fine-tuned or pre-trained for Persian.
- **Encoder & BERT-style Models** — BERT, RoBERTa, T5 and similar encoder models for Persian NLU.
- **Embedding Models** — sentence/paragraph embedding models optimized for Persian.
- **Text-to-Speech (TTS)** — models that generate Persian speech from text.
- **Speech Recognition (ASR / STT)** — models that transcribe Persian speech to text.
- **Text-to-Image Generation** — models that generate images from Persian text prompts.
- **Image Captioning & Vision-Language** — models that generate Persian captions from images.
- **OCR Models** — models for Persian optical character recognition.
- **Tokenizers** — tokenizers designed for Persian text.
- **Datasets** — Persian language datasets for training and evaluation.
- **Benchmarks & Leaderboards** — evaluation benchmarks and leaderboards for Persian AI.
- **Tools & Frameworks** — libraries, platforms, and tools for Persian AI development.

## Quality Guidelines

- The resource must be freely accessible (open weights, open data, or open source code).
- Prefer models with available weights on Hugging Face or GitHub.
- Include a brief, accurate description of what the model/tool does.
